# WT Energy

Windows 8111 能量面板与静态 SEP 研究原型。仅使用 Python 标准库，无需安装第三方包。

## 在 Windows 上运行

使用 Python 3.11 或更新版本，安装时保留 **Tcl/Tk** 和 Python Launcher。将整个目录复制到 Windows 后，双击 `start_windows.cmd`。默认连接本机 `http://127.0.0.1:8111`；未进入有效飞行时显示等待状态。

先查看合成演示，可在项目目录的终端运行：

```bat
start_windows.cmd --demo
```

加载附带苏-27SM 模型，使用手动指定的 **23,000 kg 参考总质量**：

```bat
start_windows.cmd --model data\fm\su_27sm.blkx --mass-kg 23000
```

也可在界面“设置”中切换实时／演示模式、选择 FM、输入质量和切换模型军推／加力。23,000 kg 只是示例输入，不是自动识别的本机重量。手动质量不会随燃油变化。

界面支持置顶和透明度调整。窗口需在 Windows 游戏环境验证；独占全屏下可能无法显示普通置顶窗口，可以使用游戏的无边框窗口模式。

## 指标含义

- **实际 SEP**：从真空速和高度时间序列得到的总比能变化率，单位 m/s。
- **比能高度**：`h + TAS² / (2g)`，单位 m。
- **爬升／动能贡献**：同一个最长 1.2 秒窗口的变化率，两者相加等于实际 SEP。显示存在平滑时延。
- **静态参考 SEP**：所选 FM 在当前高度、给定参考质量、1g、干净构型下的预测。油门由模型设置选择全军推或全加力，不跟随实时油门。
- **采样最高 SEP**：默认在当前 TAS 的 70%–130% 区间取 13 点。它不是全飞行包线的最优值，也不是到达目标高度的最短时间轨迹；边界和无效样本说明可在“说明”中查看。

模型参考不代表实际当前机动。实时机型未知或与所选 FM 不匹配时，预测停用；遥测能量仍可独立显示。演示模式始终标记为合成数据，不会自动接替失败的实时连接。

## 已实现与适用范围

8111 遥测处理和实际能量计算不限定为苏-27SM，但需要对应单位字段，尚未逐机型实测。未知可选字段保持缺失，不从燃油推算总质量，不把机体 Ny 当成任意姿态下的 L/W。

静态 FM 目前只接受附带的固定版本 `su_27sm.blkx`，不自动套用其他飞机或新版文件。气动核心移植自 Gaijin `polares`，推力算法参考 WTAPC。部件组装使用标准大气、共同来流、安装角、中立舵面、零侧滑和零转动率假设，**没有经过游戏验证**。

当前不计算下洗、流动惯性、力矩配平、挂载／损伤／改装额外阻力及发动机瞬态。仅支持干净构型、全军推／全加力；超出支持条件时返回不可用。作者对 WTAPC 喷气推力准确性的限制同样适用。

省略迎角时求 `L = n·m·g`，其中 `n` 定义为气动升力／重量；这不是纵向配平。静态接口中的航迹角不自动把 `n` 乘以余弦。若要指定近似匀速直线爬升的升力需求，可由调用方在适用条件下指定 `n ≈ cos(γ)`。

所有 14.7 机型、F-15C 金鹰和歼-11B 的模型适配尚未完成。30°／45°／90°／120° 三维最优机动目前只有请求检查与明确的不可用结果；RWR 识别和来袭导弹预测未实现。

## 无图形检查

任何装有 Python 3.11+ 的系统都可以运行无窗口演示：

```text
python -m wt_overlay --demo --headless --duration 2
python -m wt_overlay --demo --headless --duration 2 --model data/fm/su_27sm.blkx --mass-kg 23000
```

输出为带单位字段的 JSON 行。实时连接失败时输出无效状态，不生成替代演示数据。模块与集成测试：

```text
python -m unittest discover -s tests -v
```

当前开发验证覆盖无图形运行与自动测试，尚未完成 Windows 图形界面和 WT 客户端对照试飞。

算法版本、数据来源及复用许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
