# 强化学习空战辅助：设计

目标：训练一个只看玩家可得信息的策略，在整场空战中持续给出"怎样接敌、何时发射、支援多久、怎样防御、何时再进攻"的建议，再翻译成 HUD 提示。策略不操控飞机，玩家负责全部操作与发射。

衡量标准不是策略本身多强，而是**同一个"类人"飞行员有建议与无建议相比，死得少、换得多**，尤其是针对常见死法：第一波 BVR 不躲、左飞规避被抓、第二轮交战扭不过来、直冲对面不会躲。

证据等级沿用 missile_sim：A = 游戏文件原值，C = 玩家实测或回忆，D = 推断或假设。

## 2. 玩家人群：打法原型

队友和对手都从下面的原型中抽取。每个原型再与技术水平交叉："普通"为 85% 会反应、其中 60% 做对，"高手"总能做对，与命中概率模型一致。各原型的比例每局随机，避免策略只会对付一种固定组合。

| 原型 | 行为 | 待定参数（初值为 D） |
|---|---|---|
| 左飞（多数） | 爬高并向本队左侧飞；多数直接规避，部分先向右转（朝敌方）打一发压制再规避；向左转（朝外侧）规避；RWR 清空后右转回切 | 爬升高度、侧移角度与距离、打压制弹的概率、规避方式、回切条件 |
| 右飞（少数） | 镜像：向右侧飞，左转打，右转（朝自家方向）规避 | 同上 |
| 中路 | 爬高，远距离打压制弹（"抽奖"，接近 Rmax）；然后左转规避，甚至直接回家；RWR 清空后回头 | 压制弹发射距离 / Rmax、规避方向（外侧或回家）、回切条件 |
| 爬虫 | 贴地飞，利用地杂波与多径，接近后再抬头 | 飞行高度、抬头距离 |
| 冲脸 | 直冲对面，不躲或躲得晚 | 反应概率低 |

**常见走向（C，用户）**：大多数人左飞，然后右转打一波，再左转规避；右飞很少，规避时右转，朝自家方向。也就是说，**进攻时转向中间，规避时转向外侧**。中路的人远距离打压制弹（抽奖），然后左转规避，甚至直接回家。左飞的人多数直接规避，部分先打一发压制再规避。**RWR 清空后回头**，结果要么被打死，要么开始打别人。

脚本按五个阶段写：

1. 爬升侧移；
2. 可选：转向中间，打压制弹；
3. 来弹或被锁时，转向外侧或回家规避；
4. RWR 清空一段时间后回切；
5. 第二轮交战。

各阶段的切换条件包括到达高度或侧移距离、进入射程、收到告警、RWR 清空时长，切换时机带随机性。

**脚本参数（C，用户 2026-10-05；不确定的项随机）**

| 参数 | 取值 |
|---|---|
| 爬升高度 | 多数在 7500–9000 m 改平（例如 8500 m）；部分爬到约 11000 m 后俯冲 |
| 爬虫高度 | 贴地（几十到一两百米，D） |
| 压制弹发射后是否支援 | 不确定。随机：一部分马上转走，一部分偏转 30–50° 支援到导弹开机 |
| 规避动作 | 三九或掉头，会往下扎 |
| 箔条 | 连续放，或有节奏地慢慢放 |
| 回切前 RWR 清空时长 | 3–10 s，随机 |
| 第二轮发射距离 | 一般 30 km 以内开始打，有时 20 km |

"RWR 清空就回头"恰好是陷阱：TWS 发射的主动弹在开机前不会告警，对方雷达用 TWS 跟踪时也不会出现锁定告警，所以 RWR 清空不等于安全。环境要能复现回切时被静默导弹打中的情况；策略和 HUD 可以据此提示"对方可能有弹在飞，晚点回头"。

压制弹本身命中率低，价值在于逼对方规避、让出位置和时间。奖励里不惩罚发射，导弹数量有限这一点已经足够让策略学会权衡。

**打法按机型分配（C，用户 2026-10-05）**。机器可读的版本在 data/match/top_tier.json，每局在先验附近按 Dirichlet 随机：

| 机型 | 左飞 | 中路 | 右飞 | 爬虫 | 冲脸 |
|---|---|---|---|---|---|
| 台风（6 个型号） | 0.25 | 0.55 | 0.05 | 0.07 | 0.08 |
| 歼-16、苏-30SM2（中路的也常打一发就提早左转） | 0.70 | 0.15 | 0.03 | 0.07 | 0.05 |
| F-15C 金鹰、歼-15T（攒能量） | 0.85 | 0.05 | 0.02 | 0.05 | 0.03 |
| 苏-30SM/MKM、F/A-18E/F、米格-35（载弹多或机动好） | 0.60 | 0.12 | 0.15 | 0.07 | 0.06 |
| F-16V/CM、歼-10C、JAS 39E | 0.40 | 0.25 | 0.10 | 0.15 | 0.10 |

各机型都可能当爬虫。

两队都向各自左侧绕时，左飞的人会互相错开，形成旋转门式的走位：A 队左飞的人面对的是 B 队的右侧（中路和少数右飞）。左飞的人往外侧规避后要转回来，回切时往往被抓，环境需要能复现这一点。地图约 128 km 见方，左飞的人往外侧规避时会被边界挡住，可规避的横向空间大约只有几十公里。

## 2.1 后续：对手扰动（用户 2026-10-06）

S1 的 v3 学会了"Rmax 处先打一发，开机时正好卡在对方爬完转头"。它按自己的 TWS 观测开火（距离约等于 Rmax，出生越远开火越晚），这是想要的；但脚本的节奏比真人整齐，策略可能只适应了这一种节奏。之后给脚本加扰动，让同一原型每局表现不同：

- 时机：爬升改平高度、转头进攻的时刻、回切前的等待、第二轮发射距离，放宽分布并加偶发的极端值（很早或很晚转头、不转头直接回家、规避一半就回切）；
- 动作：规避方向偶尔反着来、规避中途改主意、压制弹后支援或不支援；
- 节奏：同一局里不同阶段的反应延迟不同。

实现（2026-10-06 夜，未启用）：MatchEnv 配置 `script_perturbation`（字典，键见 `archetypes.PERTURBATION`，`{}` 用默认值）。每架脚本机用自己的随机数，按概率 `p`（默认一半）被扰动：改平高度 5000–11500 m 且就在那里算"爬完"（原来受控执行时一律按 8000 m 判定，转头时机因此很整齐），一半人爬完后再侧飞 0–45 s 才转头，回切等待 1–25 s，第二轮发射距离 12–40 km，压制弹有无翻转（30%）和发射距离 0.6–1.2 Rmax，反应延迟乘 0.5–2，20% 的人规避 5–15 s 就提前回切（RWR 还没清），15% 的人往内侧规避。原型和水平不变，飞机和出生点不变。不设时与改动前逐位一致（脚本 2v2 两局 + 环境一局对比过）。

已知缺口：脚本不会打贴地的目标（用户：疏忽，不是最大的问题，希望 AI 以后自己学会）。加红外弹和机炮时，脚本也要会下去收贴地的人。

超时：S1 起用 `timeout_reward = -0.5`（用户 2026-10-06），躲到时间结束不再白拿 0 分。

结构速度（用户 2026-10-06）：游戏里超过 VNE 直接撕翼，模拟器原来没有这条规则，贴地飞机能跑到 1,600–2,100 km/h 而导弹追不上，s1_ego 后期因此学成贴地流（第 242–262 轮考试 45% 的弹在 300 m 以下发射）。已加可选的 `structural_speed`；同一批分析显示 100 m 目标在 12 km 内迎头 / 侧向命中 8/11，贴地目标没打中的弹 92% 是动能耗尽，导引头本身没问题。

坐标无关（用户 2026-10-06）：真实地图出生点不一定正南正北，可能是对角线或偏一边，所以观测只用相对量（`observation_frame = "egocentric"`），训练时出生方向随机旋转并偏移（`spawn_layout`）。游戏里需要的"自家 / 敌方基地方位"和地图边界都能从 8111 的地图信息得到。

## 3. 环境

所有物体按共享时钟同步推进。导弹控制节拍 1/48 s 不变；每一步先推进飞机，再推进导弹。

- **飞机**：wt_overlay 的飞行模型驱动（ManeuverModel），全部 138 架可用。
- **导弹**：missile_sim 改为可以逐步推进的实例（可选模式，旧接口结果逐位不变）。
  - 发射瞬间单独给出位置、速度和朝向。
  - 发射方状态通过回调提供，不再按发射时速度直线外推。
  - 允许多枚导弹同时在飞。
  - 关闭"提前判定脱靶"的捷径。
- **雷达**：按 data/units 中每部雷达的参数建模。
  - 扫描图案按时间推进；探测距离按目标 RCS 换算；包含多普勒 notch 和地杂波。
  - TWS 航迹按建立时间、外推和超时规则维护。
  - 电扫雷达在可转动范围内快速刷新已有航迹；机扫雷达只在扫描区内刷新。
  - STT 有记忆时间。
- **RWR**：按每架飞机的 RWR 参数，包括接收扇区、能否测向、保持时间、能否识别 STT。主动弹开机时告警；空空雷达没有发射告警。
- **其他观测**：MAW（有的机型才有）、动力段尾焰可见、地图标记（只有平面坐标，带时间）、视距内目视发现。
- **箔条**：数量有限，与箔条模型一致。
- **击落判定**：引信触发即击落（D）。一方被击落后，空中导弹继续结算。

## 4. 观测、动作、执行

**观测**：本机状态，加一个不定长实体列表。列表包括雷达航迹、RWR 告警、地图标记、目视目标、本方在飞导弹、来袭告警、队友。每个实体带来源、更新时间、是否外推，以及性能描述（飞行模型、雷达、导弹）。策略输入不含模拟器真值。

**动作**：每秒 1–2 次决策。

- **机动意图**：相对某个航迹、威胁或队友的方向，高度带，速度要求。
- **雷达**：模式、天线俯仰、扫描范围。
- **武器**：打哪个目标，现在打还是等。
- **支援**：继续支援，或放弃并调整飞行。
- **观察**：往哪个方向看。
- **时机**：保持当前动作，或切换。

**操纵方式与视角（C，用户 2026-10-05）**：

- 玩家用鼠标瞄准飞，也会用键盘。
- 自由视角用得很多。自由视角时镜头离开瞄准方向，鼠标不再控制飞机，只能靠键盘飞。
- 键盘按"满舵"处理：滚转、俯仰各取 −1、0、+1，默认全量；有人会限制舵量，用一个小于 1 的系数表示。满舵仍受每架飞机自身的限制（过载限制器、电传模式、结构强度），这些限制尽量取自飞行模型文件。
- 因此动作分三类：
  - 鼠标瞄准意图；
  - 键盘粗操纵；
  - 视角（瞄准方向，或自由视角看向某个对象或方向）。

  自由视角期间屏蔽鼠标意图，只能用键盘动作。
- 目标框与参数、导弹标、目视发现只有在镜头视场内才可见；雷达 B 显、RWR、地图不受限制。
- 镜头视场（游戏文件 config/camera.blkx，A）：第三人称 90°，缩放时 30°；座舱 90°，虚拟座舱 85°；左右看预设 ±110°，后看 180°。90° 按水平视场理解（D）；若是垂直视场，16:9 下水平约 121°。画面内目标框和参数的距离限制未知（D）。

**执行**：动作交给飞行模型驱动的脚本飞行员执行。中间经过玩家执行模型：反应延迟（对数正态，中位 1.5 s）、跟随误差、偶尔不执行。策略下一步依据实际发生的状态重新决策。

## 5. 训练

- **算法**：共享参数的带记忆 PPO。用注意力层处理实体列表，GRU 做记忆，1 对 1 到 16 对 16 用同一个网络。评估网络可以看真值。
- **对手与队友**：一个联盟，包括脚本原型、策略的历史版本和专门找漏洞的对手。队友默认是原型脚本。
- **奖励（用户 2026-10-05）**：击落 +1，被击落 −2（含撞地），助攻约 +0.3，团队胜负不计。不奖励发射次数，也不按存活时间加分。脱离、超时、互相击落分别记录。
  - 助攻的初步定义：目标被队友击落前约 20 s 内，自己有导弹正在飞向它，或者自己的导弹逼得它规避过。
  - 奖励按个人计算，所以这是一个"非零和"的多人博弈：同队之间不强制合作，只靠助攻奖励引导配合。
- **一局 = 多条经验流**：一局 16 对 16 里，每架由当前策略控制的飞机各自产生一条轨迹和奖励。同一局的仿真成本不变，控制的飞机越多，每单位算力得到的样本越多。同一局内的样本彼此相关，有效样本量小于 32 倍。
- **每局的控制分配**：
  - 一部分局全由策略及其历史版本控制，提高强度；
  - 大部分局只让策略控制 1–8 架，其余是打法原型，贴近实际使用（队友和对手都是真人）。
  - 只有当前策略控制的飞机的轨迹用于 PPO 更新。
- **课程**：
  1. 1 对 1，对手为各原型；
  2. 2 对 2、2 对 1、1 对 2；
  3. 从整局局面中截出的局部交战，带第三方威胁，每段 2–5 分钟；
  4. 8 对 8；
  5. 16 对 16 整局，用于评估和最后阶段训练。
- **起始状态**：多数回合从整局的接敌前后开始，而不是从出生开始。这样关键决策的样本占多数，奖励也容易归到正确的那一步。
- **每架飞机都不同**：一局 32 架机型各异，靠以下几点处理：
  - 一个策略网络服务所有机型，输入里带本机性能描述：当前状态下的过载、推重比、阻力，雷达和 RWR 参数，导弹性能与剩余数量，干扰弹数。
  - 敌机型号：RWR 识别出雷达类型后，借 data/units 的雷达对应关系换成敌机性能描述；认不出时用本 BR 段的平均值。
  - 价值网络同样看机型，避免把"飞机弱"误判成"动作差"。
  - 策略控制的位置按机型均匀抽，冷门机型也有足够样本。
  - 所有指标按机型分开统计。
- **泛化**：在 BR 14.3–14.7 先留 2–3 种机型（例如 JAS 39E、米格-35）不参加训练，只用于测试；扩展到其他 BR 段时再留出 1–2 种导弹。

## 6. 评估

- 同一个类人飞行员，有建议与无建议各打一批整局，比较死亡率、互换比和无效耗弹。
- 按原型分组看死法：左飞被抓、第一波不躲被击落等是否减少。
- 加入执行延迟和误差后，收益是否仍然存在。
- 与规则基线在同等信息、同等执行条件下比较。

## 7.1 后续：近距离武器（红外弹、机炮）——迁移学习

用户 2026-10-05 决定：红外弹在顶级房不是很重要的部分，先不做，以后用迁移学习加进来。

- **BR 14.3–14.7 的红外弹（游戏文件 A）**：AIM-9M（11 架）、AIM-9L/i（台风）、PL-8B（歼-10C、歼-15T、歼-16）、R-73 / R-73E（苏-30 系、米格-35）、R-27ET、Magic 2（阵风）、Rb 74M（JAS 39E）。没有 AIM-9X、IRIS-T、PL-10。
- **缺口**：
  - missile_sim 有这些弹的参数，但内核没有红外导引头模型和热焰弹模型，现在这些弹实际上按完美跟踪飞行。
  - R-73 / R-73E（以及 MICA EM）有推力矢量，模拟器目前排除。
  - 环境里没有机炮。
- **迁移方式**：
  - 扩展动作头：武器头从"不打 / 打"扩为"不打 / 主动弹 / 红外弹 / 机炮"，干扰弹头分为箔条和热焰弹。
  - 现有输出权重保留，新增输出从小初值开始，从当前策略继续训练。
  - 补上红外导引头、热焰弹、推力矢量（missile_sim）以及简化的机炮模型。
- **在此之前**：策略学到的近距离经验偏乐观（不会被红外弹和机炮击落），评估时近距离打法不作数。
